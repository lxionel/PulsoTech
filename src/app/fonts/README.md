# Fuentes locales

Estos WOFF2 son los mismos archivos de Google Fonts (subconjunto latino)
que utilizaba la compilación de PulsoTech con `next/font/google`.
Incluyen las letras y acentos del español. Se conservan los pesos variables
300–800 de Plus Jakarta Sans y 400–700 de Space Grotesk.

`next/font/local` permite compilarlos sin descargar fuentes de Google
durante el despliegue. No se modificaron los archivos tipográficos.

Las licencias SIL Open Font License 1.1 se incluyen en `public/licenses/`
y se publican junto con la tienda. Procedencia de las licencias:

- https://github.com/google/fonts/tree/main/ofl/plusjakartasans
- https://github.com/google/fonts/tree/main/ofl/spacegrotesk
